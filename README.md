# Hanna's Portfolio

A place for the things I've made, the things I'm learning, and the occasional reminder that I actually do know what I'm doing.

This is my personal portfolio, built from scratch with React and Vite. It's meant to be more than a collection of projects and a copy of my resume. I wanted a place where I could show how I approach problems, what I've worked on, and what I'm interested in building next.

## What's here

A little bit of everything:

* Projects I've built through school, work, and on my own
* A closer look at the technologies I work with
* Information about my background and experience
* A few things that don't fit particularly well on a resume
* My resume and ways to get in touch

The portfolio will probably change as I do. That's sort of the point.

## Built with

* React
* JavaScript
* Vite
* HTML
* CSS

Nothing particularly exotic. The interesting part is what I chose to build with it.

## Running it locally

If you want to poke around in the code:

```bash
git clone https://github.com/hannawhitney/portfolio.git
cd portfolio
npm install
npm run dev
```

Then open the local development URL Vite gives you.

## A note about this project

A portfolio is a slightly strange thing to build.

It's a website whose main job is to explain the person who built it, while also being one of the things that person built.

So yes, this project is also an example of my work.

I'm still learning, still improving, and still occasionally staring at a CSS problem wondering how it got to this point. But that's part of being a developer, too.

Thanks for taking a look.
